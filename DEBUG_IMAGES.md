# Инструкция по исправлению проблемы с изображениями

## Шаг 1: Очистите кеш браузера и localStorage

1. Откройте браузер (Chrome/Firefox/Edge)
2. Нажмите **F12** (или правой кнопкой → "Просмотреть код")
3. Перейдите на вкладку **Application** (или **Хранилище** в Firefox)
4. В левом меню найдите **Local Storage** → выберите ваш сайт
5. Найдите ключ `userItems` и **удалите его** (правой кнопкой → Delete)
6. Нажмите **F5** для перезагрузки страницы

## Шаг 2: Проверьте консоль браузера

1. Откройте консоль (F12 → вкладка **Console**)
2. Обновите страницу (F5)
3. Посмотрите, есть ли ошибки (красные сообщения)
4. Если есть ошибки, скопируйте их и сообщите мне

## Шаг 3: Проверьте загрузку изображений

1. Откройте вкладку **Network** (Сеть) в DevTools
2. Обновите страницу (F5)
3. В фильтре выберите **Img** (изображения)
4. Посмотрите, какие изображения загружаются:
   - ✅ Зеленые = загружены успешно
   - ❌ Красные = ошибка загрузки

## Шаг 4: Проверьте пути к изображениям

1. В консоли (F12 → Console) выполните:
```javascript
console.log(JSON.parse(localStorage.getItem('userItems')))
```

2. Проверьте, что у каждого предмета есть поле `image` с правильным путем, например:
   - `"image": "images/WashingMachine.png"` ✅
   - `"image": null` ❌
   - `"image": ""` ❌

## Шаг 5: Если ничего не помогло

1. Удалите все из localStorage (Application → Clear storage → Clear site data)
2. Перезагрузите страницу
3. Добавьте предметы заново
4. Проверьте, отображаются ли изображения
