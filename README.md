# 🏠 Домашняя уборка - Telegram Mini App

Мини-приложение для Telegram, которое помогает следить за чистотой в доме и мотивирует на регулярную уборку.

## 🎯 Функционал

- ✅ Добавление предметов быта на главный экран
- ⏰ Автоматический таймер для каждого предмета
- 🦠 Визуальное отображение "грязи" (микробы появляются со временем)
- 🧹 Отметка уборки - предмет снова становится чистым
- 💾 Сохранение данных в localStorage

## 🚀 Запуск на GitHub Pages

1. Создайте репозиторий на GitHub
2. Загрузите все файлы в репозиторий
3. Перейдите в Settings → Pages
4. Выберите источник: Deploy from a branch
5. Выберите ветку: main (или master)
6. Сохраните настройки
7. Ваше приложение будет доступно по адресу: `https://ваш-username.github.io/название-репозитория/`

## 📱 Подключение к Telegram Bot

1. Создайте бота через [@BotFather](https://t.me/BotFather)
2. Используйте команду `/newapp` для создания мини-приложения
3. Укажите URL вашего GitHub Pages
4. Настройте бота и запустите!

## ⚙️ Настройки

В файле `app.js` можно изменить параметры:

```javascript
const CONFIG = {
    CLEAN_INTERVAL_MINUTES: 5, // через сколько минут появляются первые микробы
    GERM_STAGES: 5, // количество стадий загрязнения
    STAGE_INTERVAL_MINUTES: 2 // интервал между стадиями
};
```
